## Implemented source

- SQLite schema v2 with migration backups, persistent plans/tasks/attempts/verification/artifacts/events, dependency gates, scoped ownership, revision conflicts and explicit resume. No client can set a task completed without verification. Source/environment changes invalidate affected proof; restart never replays commands or writes.
- Optional plan/task context on existing tools, actual job/change/artifact links, new retry attempts, current criteria rebinding, and cancellation limited to owned tasks/jobs/sessions.
- Immutable PNG/JSON evidence with hashes, source revision/path, capture time, viewport/clip/window metadata, bounded previews, actual MCP image blocks and visual diffs. Browser checks persist accessibility/layout/network/runtime diagnostics. Clip captures can cover long pages; keyboard output is a focus sample rather than a complete certification.
- Project context, source/asset/monorepo mapping, lazy source-hash reuse keyed by file identity/ctime/mtime, and bounded JS/TS search/symbols/definitions/references/diagnostics. Local tsconfig inheritance and aliases work without loading project plugins. Astro is indexed as source text; semantic Astro support is not claimed.
- Pinned React/Vite, Astro + React, Next App Router, Next/Prisma/SQLite/Better Auth and Electron templates, design presets and inspect-before-add shadcn registry support. Full-stack APIs include per-user create/read/update/delete operations. Tauri currently has an experimental scaffold only.
- Sandboxed Electron launch/window actions/logs/screenshots and packaged .app/.exe launch paths, isolated userData and owned shutdown. No arbitrary main-process evaluation is exposed through desktop tools.
- OS-backed environment vault with scoped injection and loaded/locked status, split-stream plaintext log redaction, safe Git checkpoints using an isolated index, and conflict-safe file recovery.
- Inert Skills import from directory/ZIP/pinned GitHub commit, discovery/resources, enable/disable/update/uninstall and hash-specific local script authorization. Changed versions disable execution and clear authorization. Local reads verify open descriptors; archives and downloads have size budgets.
- Activity pagination, evidence panels, environment/Skills UI, Stop all owned work, private support bundles, conservative artifact retention and opt-in background helper. The source helper survives Quit; packaged login registration remains a separate platform gate.
- Frozen, integrity-checked service/UI copies, stable retained connection entry points, agent build identity and bridge catalog matching. An older agent cannot silently stand in for a newer GUI. Config migration preserves the same credential and unrelated entries.
- macOS native scope census/recovery recognizes detached descendants using isolated Seatbelt capabilities and verifies persisted birth/file identities. Missing parents are never proof of ownership. Native descriptor guards also have Windows source/build integration; Windows execution is unverified.
- The historical running app had a stopped renderer and no live agent socket, leaving a white window. The updated GUI recovers a stopped renderer once, provides native recovery for repeated failures, and shows startup/React failures explicitly. Agent transport loss reconnects the current build and its vault/subscription without replaying commands. Startup probes are bounded and agent launch errors are recorded separately. Development services resolve relative to the built entry point rather than the shell's working directory.
- The Electron starter now allows React/Vite refresh only in development CSP and displays IPC results in the page. The full-stack account UI includes real inline note editing, request errors, loading/disabled states and session-bound note loading. Asset revisions include file identity and nanosecond ctime/mtime.
