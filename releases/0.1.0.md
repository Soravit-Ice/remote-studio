# Remote Studio 0.1.0

Remote Studio connects authorized local workspaces to MCP clients with native
file permissions, command isolation, recovery checkpoints and activity history.

- Workspace roots survive macOS volume device changes; original-folder
  recovery retains existing workspace and client permissions.
- Paid RS licenses use the T2ETECH License SDK, native OAuth callback and
  installation-specific encrypted storage. Trials are disabled.
- New templates pin Rollup to the version verified with this source tree.
- Windows current-folder resolution accepts `.` and still rejects workspace
  escapes and ambiguous path components.

Unsigned installers require manual installation and updates. Signing and
notarization flags in the release manifest describe the actual verified build.
