# Remote Studio 0.2.3

- Require an activated Remote Studio purchase or license key before creating, exporting or starting assistant connections.
- Check paid access for every MCP workspace read, tool call, skill resource and artifact request, including connections saved by earlier versions. Expired or deactivated licenses cannot keep reading through an existing bridge.
- Stop the ChatGPT tunnel when its connection or license is no longer authorized, and stop both tunnel providers on device deactivation.
- Show activation requirements throughout the app and load saved activation state before displaying connection access. Activated license keys continue to work without account sign-in.
- Use the supplied blue R logo in the application, macOS bundle and Dock, Windows icon, tray and Store listing.

Local setup, local browsing and stopping owned work remain available without activation. This release ships the verified macOS Apple Silicon installer. It remains unsigned and uses manual installation and updates.
