# Remote Studio 0.2.2

- Connect Gemini Web to scoped local workspaces through supervised Cloudflare tunnels, native OAuth approval and encrypted connection storage.
- Create motion graphics with nine Video tools: scaffold a project, validate it, capture frames, preview in Studio and render MP4, WebM or MOV through native sandbox jobs.
- Preserve existing workspace permissions, command review, execution-time license checks and revocation across both stdio and HTTP MCP connections.
- Improve foreground/background connection recovery and persist acknowledged settings.

- Report the actual package version consistently in the app, MCP server, retained runtime and support bundle.

- Build native macOS helpers for the same macOS 13 deployment target declared by the app, independently of the build machine SDK.

Remote Studio uses the production T2ETECH Store configuration for product RS. A paid activated license is required for protected work; trials are disabled. Optional video and tunnel runtimes are installed on demand.

Unsigned installers use manual installation and updates. Release artifacts describe their actual signing and notarization status. Platform support is limited to the native targets that pass this release's build and packaged acceptance gates. Real Gemini account setup and physical login/reboot acceptance remain separate from automated tests.
