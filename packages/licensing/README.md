# Licensing module

The authenticated local agent owns the signed T2ETECH SDK for product RS. Electron passes an OS-protected installation key through trusted local administration; SDK state is encrypted and never exposed to the renderer or MCP. Verified paid `export` claims gate Remote Studio file changes and execution. Setup, reads and owned-work cancellation stay available. Source fixtures require explicit unpackaged temporary-data tests; packaged execution stays enforced. See [release preparation](../../docs/RELEASE.md).
