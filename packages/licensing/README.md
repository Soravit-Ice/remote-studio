# Licensing module

The authenticated local agent owns the signed T2ETECH SDK for product RS. Electron passes an OS-protected installation key through trusted local administration; SDK state is encrypted and never exposed to the renderer or MCP. Verified paid `export` claims gate assistant connection creation, credential export, MCP initialization, every client read/resource/tool request, file changes and execution. Existing clients are rechecked on every request. Local UI setup, local reads and owned-work cancellation stay available. A paid key activation is sufficient without account sign-in. Source fixtures require explicit unpackaged temporary-data tests; packaged execution stays enforced. See [release preparation](../../docs/RELEASE.md).
